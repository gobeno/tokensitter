# Tokensitter

See what your Claude work really costs and what you could save. Reads local logs only; nothing leaves your machine.

## Claude Code

Run both in Claude Code:

```
/plugin marketplace add gobeno/tokensitter
/plugin install tokensitter@tokensitter
```

## OpenAI Codex

Run these in your normal terminal (not inside Codex), then start Codex:

```
codex plugin marketplace add https://tokensitter.com/codex/mp.git
codex plugin add tokensitter@tokensitter-codex
codex plugin add tokensitter-hooks@tokensitter-codex
```

Website: https://tokensitter.com
